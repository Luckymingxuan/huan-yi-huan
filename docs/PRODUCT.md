# 缓一缓：产品基线

本文档记录项目当前已确认的目标、愿景、要求与限制。后续设计和开发应以此为共同基线；出现新决策时，先更新本文档，再调整实现。

## 产品愿景

“缓一缓”希望在人情绪升高、可能说出或做出冲动行为之前，提供一个及时而克制的打断。

产品不评判情绪，也不试图代替心理咨询。它只帮助用户意识到“此刻的情绪正在升高”，留出一个短暂的缓冲空间。

## 当前产品范围

核心业务仍集中在一个情绪检测页面，另增加一个只服务于提醒方式选择的设置页面。不增加登录、报告、社区等其他功能页面。

这个页面完成一条连续体验：

1. 进入页面并开始检测实时语音情绪。
2. 用“情绪值”实时反馈当前愤怒与厌恶的综合强度。
3. 当情绪值升高时，通过颜色变化提醒用户。
4. 上滑查看刚才到现在的变化，并选择任意时间点回看。
5. 查看历史时检测仍持续进行。
6. 用户可以在设置页从“回放刚才 8 秒”和三种内置声音中选择一种高情绪提醒方式。

## 核心概念

### 情绪值

- 当前版本通过 FastAPI WebSocket 后端识别实时语音中的愤怒与厌恶概率，并合成为一个 `0–100` 的相对值。
- 综合公式为 `100 ×（0.9 × max(愤怒, 厌恶) + 0.1 × min(愤怒, 厌恶)）`：以更强的负面情绪为主，同时保留另一项的叠加影响。
- 这个值用于及时预警，不是医学或心理学意义上的情绪诊断。
- 后端概率和三档阈值仍需根据真实使用数据继续校准。

### 三档状态

暂定阈值，后续根据真实使用数据调整：

| 情绪值 | 状态 | 颜色 | 意图 |
| --- | --- | --- | --- |
| `0–44` | 平稳 | 蓝色 | 保持觉察，不制造焦虑 |
| `45–71` | 升高 | 橙色 | 温和提醒用户留意 |
| `72–100` | 强烈 | 红色 | 明确提示先停一下 |

## 页面结构

- 页面右上角固定显示“设置”按钮，不在这里展示等待、倾听或暂停状态。
- 点击“设置”进入 `/settings` 提醒方式选择页；返回后主页使用新的选择。

### 提醒方式设置页

- “回放刚才 8 秒”与三种内置声音是同一级别的四个单选项，彼此互斥，任何时刻只使用一种提醒方式。
- 默认选择“回放刚才 8 秒”；选择它时只回放触发前最多 8 秒的本地语音，不播放内置声音。
- 选择任意内置声音时只播放该声音，并且不维护 8 秒本地回放缓冲。
- 三种内置音频均可逐个试听；`Fire alarm audio` 在界面显示为“消防车”。
- `emotion` 在界面显示为“10年情感”。
- `bell` 在界面显示为“下课铃”。
- 选择保存在当前设备，不上传云端。
- 当前页面只负责提醒方式，不扩展其他通用设置。

### 高情绪提醒

- 三档视觉阈值保持不变，声音报警灵敏度在上一版基础上再提高约 15%：情绪值首次达到 `45`、进入橙色区间时触发提醒，避免在蓝色“平稳”状态报警。
- 选中“回放刚才 8 秒”时，达到报警线后先继续采集 2.5 秒，再回放截至该时刻滚动保留的最近 8 秒语音，让触发时尚未说完的句子有时间结束；记录总时长不足 8 秒时只播放已有部分。
- 选中内置声音时立即播放该声音，不等待 2.5 秒；两种提醒不会叠加。
- 2.5 秒补录期间继续向后端推送和更新缓冲；真正开始回放后才暂停推送和写入滚动缓冲，回放结束后重置后端窗口并恢复检测，避免扬声器声音被麦克风再次识别形成反馈循环。
- 情绪值降到 `39` 以下后，才允许下一次越线提醒；触发线与重新武装线同步降低，避免报警变敏感后在阈值附近反复触发。
- 两次提醒至少间隔 10 秒。
- 暂停或结束记录时停止正在播放的语音回放或提醒音频，并释放滚动缓冲。

### 收起状态

- 彩色圆环及其情绪值位于屏幕中部略偏上的位置，避免视觉重心下坠。
- 圆环颜色随三档状态变化。
- 底部是可上滑图层。
- 开始记录按钮独立放在上滑图层正上方，不能挤偏中央圆环。
- 开始记录按钮上方显示“或许我可以帮帮你”。
- 开始记录后，完整按钮以向两侧剥离的动效切换为两个同高控制：左侧圆形“暂停/继续”按钮与右侧“结束记录”按钮；切换前后视觉中心不能跳动。
- 图层保持正常的全宽底部上滑结构，不使用悬浮胶囊或独立卡片造型。
- 图层收起时只显示左侧最近一小段情绪直方图和右侧计时，不显示“最近变化”“持续记录中”“持续时间”等标题或状态文案。
- 尚未产生音频记录时，收起图层中的 `00:00` 居中显示；出现第一条音频柱形后，柱形从左侧淡入，计时从中心丝滑滑动到右侧，不能瞬间跳位。暂停或结束后若历史仍在，继续保持该布局。
- 收起状态明确划分左侧柱形区和右侧计时区：柱形不得进入计时区，计时在固定 `96px` 宽区域内居中，该区域右侧距图层边缘 `8px`。计时字号约 `31px`、字重约 `650`，并相对图层垂直中心下移 `5px`。柱子一旦生成，其宽度与高度保持固定；整组柱形相对图层垂直中心上移 `5px`。柱形起点相对图层左侧留出一个柱距，可见柱数根据剩余实际宽度计算，让最长柱形序列延伸到计时区附近，不能在较宽窗口中留下大段无意义空白。记录较短时从窗口左侧固定起点逐条向右生长，已有柱子不移动；只有填满可视宽度后，新数据才从右侧进入并推动已有柱子连续向左滚动。柱子不能随着样本增加反复缩放。

### 展开状态

- 底部图层上滑成为主要内容区。
- 中央圆环丝滑收拢，只保留顶部的情绪值；数值检测不中断。
- 主区域显示持续增长的情绪直方图。
- 展开图表采用固定柱宽，一屏约显示 24 条采样（约 12 秒），不能为了容纳全部历史而持续压缩柱子。
- 单次记录内不限制柱子数量，也不删除较早的样本；时间轴随记录持续向右增长，保证历史时间点和点击选择始终稳定。
- 图表右侧预留约 `56px` 的跟随空间；最新柱形到达该位置后开始自动向左滚动，使最新数据持续停留在右侧但不紧贴边缘。
- 自动跟随必须在每条新样本产生时继续执行，不能因为历史数组达到长度上限而停止。
- 用户主动触摸、鼠标拖动或横向滚轮浏览旧数据后暂停自动跟随，新数据不能强制拉回末尾。用户按下到松开的整个操作期间，任何滚动事件都不得重新开启跟随；只有手势结束后确认时间轴真正位于最右端，才恢复自动跟随。到达边界后继续拖动不能让跟随状态再次变为暂停。
- 黑色圆点标识当前选中的数据点。
- 用户可左右滑动或点击图表，查看对应时间和情绪值。点击任意柱形后，时间轴必须平滑移动，将所选柱形及其黑点放到可视区域正中并锁定该时间点；右侧新数据继续产生，但视口不能自动移动。即使图表点击前位于最右端，也不能被后续滚动事件立即解除；只有用户再次主动拖到最右端并松开，才解除选择锁定并恢复跟随。
- 展开图表中新生成的柱子使用渐显动画，柱形序列滚动到可视区域左右边缘时渐隐，不能突然出现或消失。
- 展开图表下方显示一条极简时间刻度尺，以细线和长短刻度表达时间连续性；每隔 5 秒在长刻度下显示一个 `mm:ss` 时间标签，超过一小时后显示 `hh:mm:ss`，文字颜色与时间轴一致。时间按有效录制时长计算，暂停期间不累计。刻度尺必须位于与柱形相同的横向滚动容器内，每个刻度与柱形使用相同间距，左右拖动时两者同步移动。手机支持触摸横滑，PC 支持鼠标按住柱形或刻度尺拖动。
- 图层可以再次下滑回到收起状态。

## 交互要求

- 页面必须支持触摸上滑、下滑，也支持点击手柄和键盘操作。
- 圆环到纯数值的变化应是连续的形态和位置动画，避免突然切换。
- 数据记录、计时和颜色更新不能因为图层展开而停止。
- 暂停时停止采样和计时，但保留已记录的数据；继续后接着同一次记录，结束后释放麦克风并保留历史供回看。
- 浏览器要求用户授权麦克风，因此首次检测必须包含明确的启动动作和权限说明。
- 麦克风权限被拒绝或设备不可用时，应给出可理解的恢复提示。

## 视觉方向

- 极简、安静、克制，借鉴 Apple 产品的内容优先、充足留白和细腻动效。
- 必须沿用项目已初始化的 shadcn/ui **Luma** 预设与 Base UI 底层。
- 避免仪表盘堆砌、强装饰、渐变滥用和游戏化表达。
- 颜色主要承担情绪状态含义，其余界面保持中性。
- PC 与手机保持同一信息结构和交互逻辑，不设计两套产品；以手机端尺寸和触控为第一优先级。

## 技术与隐私限制

- 当前使用浏览器 Web Audio API 采集音频，将其重采样为 16 kHz 单声道 Int16 PCM，并实时发送给 FastAPI WebSocket 后端分析。
- 麦克风优先请求 48 kHz 单声道人声采集，并启用浏览器的回声消除、降噪和自动增益；本地回放再按峰值做有限增益，提升偏小录音的清晰度且避免削波。
- 仅当提醒方式选中“回放刚才 8 秒”时，浏览器才在内存中以设备原生采样率保留固定容量的最近 8 秒单声道 Int16 PCM（常见 44.1/48 kHz 时约 706/768 KB），新音频持续覆盖旧音频；用于后端识别的音频仍单独重采样为 16 kHz，不保留完整会话，不写入磁盘，不上传滚动缓冲。
- 达到报警线时在本机播放该内存快照；播放结束、暂停、结束记录或刷新页面后释放相关缓冲。
- 音频在识别期间仍会实时传输到配置的后端服务。
- 刷新页面后历史数据可以清空；持久化不在当前范围内。
- 当前情绪值只反映模型对愤怒与厌恶的相对判断，不能作为诊断依据。
- 麦克风通常只允许在 `localhost` 或 HTTPS 环境使用。
- HTTPS 页面连接后端时，后端也必须提供 `wss://`，否则浏览器会拦截混合内容。
- 页面在后台、设备锁屏或系统限制麦克风时，检测可能暂停。

## 当前不做

- 不做语义分析，也不把情绪识别结果解释为诊断。
- 不做诊断、治疗建议或危机干预承诺。
- 不做账号系统、云同步、长期报告和多人功能。
- 不长期保存原始音频，只允许当前会话内固定 8 秒的易失性滚动缓冲。
- 不扩展登录、报告、社区或其他业务页面。

## 当前验收标准

- 手机和 PC 均可进入同一个核心页面。
- 用户授权后能看到实时变化的情绪值。
- 情绪值来自后端 sliding 模式返回的愤怒与厌恶概率，不再使用麦克风分贝或振幅计算。
- 蓝、橙、红三档颜色按阈值切换。
- 收起状态显示圆环、近期小直方图和检测时长。
- 图层可顺滑上滑展开、下滑收起。
- 展开时圆环消失但情绪值保留，检测继续。
- 展开图表支持选择历史点，并显示该点的时间与情绪值。
- 设置按钮可进入提醒方式设置页；“回放刚才 8 秒”与三份内置音频均可选择，三份音频均可试听。
- 未选择时默认使用“回放刚才 8 秒”；四种提醒方式互斥，不同时播放。
- 情绪值达到报警线 `45` 时执行选中的提醒方式：补录 2.5 秒后回放截至该时刻最近 8 秒语音，或立即播放选中的内置声音。
- 页面基于 Luma 预设，lint 和生产构建通过。
